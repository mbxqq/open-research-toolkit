# Maintenance

Repository owner and maintainer: [@mbxqq](https://github.com/mbxqq).

This is an early-stage project. Changes have been prepared with Codex assistance;
repository ownership is not evidence of external adoption or long-term maintenance.
No external users, downloads, institutional endorsements, or program acceptance are claimed.

## Review and release process

- Reproduce bugs with minimal synthetic data, and add a regression test.
- Explain behavior changes and compatibility in each change description.
- Build and install the wheel, run tests and the example, and check GitHub Actions.
- Update both version declarations and CHANGELOG for a new version.
- Review contributions for correctness, privacy and scope before accepting them.
- Record real usage or feedback only with a verifiable source and permission to share.

Contributions are welcome through issues and pull requests. Response times are not guaranteed.

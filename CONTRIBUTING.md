# Contributing

We welcome reproducible bug reports, documentation improvements, and well-scoped pull requests.

1. Open an issue describing the problem or feature and expected behavior.
2. Fork the repository and create a focused branch.
3. Add or update unit tests for code changes.
4. Run `python -m unittest discover -s tests -v`.
5. Open a pull request explaining your change and any limitations.

Please do not upload confidential, identifiable, or patient-level data in issues or pull requests. Use synthetic examples.
